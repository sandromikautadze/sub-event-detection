# Sub-Event Detection

**Authors**: Lara Hofman, Sandro Mikautadze, Elio Samaha

This project aims to predict the presence of specific sub-events in tweets posted during the 2010 and 2014 FIFA World Cups. Our solution was ranked **5th out of 115 teams**.

## Repo Structure

- ```models/```: Pretrained weights of the fine-tuned models used in the project.
- ```notebooks/```: All exploratory and development notebooks.
_Yes, it's a bit messy—we’re well aware._
- ```predictions/```: CSV files containing our model predictions used for evaluation.
- ```processed_data/```: Embedding vectors obtained through various preprocessing techniques.
- ```baseline.py```: The baseline model provided as a starting point for the task.
- ```report.pdf``` and ```slides.pdf```: Our final project report and the presentation slides.
- ```submission.py``` and ```utils.py```: Scripts used to generate and format the final submission.


⚠️ **Note**: We reorganized some files after the project deadline to improve clarity for the repo. As a result, some scripts may require path adjustments to run properly.
